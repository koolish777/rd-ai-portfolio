# 研究開発・AIシステム設計

**[ポートフォリオを開く](https://koolish777.github.io/rd-ai-portfolio/)**

試験データ解析、PLC制御・自動化、監視画面、3Dモデル・図面を、低温通電試験の例題で紹介する1ページの技術資料です。

## ページでできること

- 8試験の一覧を絞り込み、同じページの波形モニターへ移動。
- 試験の切り替え、波形の拡大、測定値の表示。
- 装置の全体・内部・組立図・部品図の切り替えと拡大。
- PLCのインターロック・独立遮断を含む装置制御の構成確認。

試験データは公開用の合成データ、人物画像はAI生成イメージです。掲載する装置は構想設計例です。
公開ファイルはLPの表示・操作用です。3Dはレンダリング画像とSVG図面を掲載しています。

## 主なファイル

- `index.html`：本文と画面の配置。
- `onepage.css`：PC・スマートフォンのレイアウト。
- `onepage.js`：試験の絞り込み、波形表示、図面の拡大。
- `assets/monitor-data.js`：8試験の合成データ。
- `assets/`：画像、日本語フォント、利用許諾文。
- `details/cad/`：組立図・部品図のSVG。

## 手元で開く

Code → Download ZIP で展開し、`index.html`をブラウザーで開きます。
