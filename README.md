# 研究開発・AIシステム設計

**[ポートフォリオを開く](https://koolish777.github.io/rd-ai-portfolio/)**

このリポジトリには、ポートフォリオの表示と操作に使うファイルを置いています。

## ページの仕組み

- **index.html**：本文、システム構成、データ構造、各画面の配置。
- **onepage.css**：PC・スマートフォンのレイアウトと見た目。
- **onepage.js**：メニュー、監視画面の状態切替、波形表示、図の拡大。
- **assets/monitor-data.js**：画面で選択する試験の表示用データ。
- **assets/**：ページで表示する画像、データ構造の図、日本語フォントとその利用許諾文。
- **details/cad/**：ページで表示・拡大する組立図と部品図のSVG。

試験データは公開用の合成データです。画面内の操作はブラウザー上で動作します。

## 手元で開く

**Code → Download ZIP** でダウンロードし、展開したフォルダーの **index.html** をブラウザーで開きます。
