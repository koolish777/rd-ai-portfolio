# 研究開発AIハーネス

**[1ページの技術サンプルを開く](https://koolish777.github.io/rd-ai-portfolio/)**

AIハーネスエンジニアリングを主題とした個人の技術資料です。仕事の分解、指揮・作業・独立監査の役割設計、ツール接続、修正・再照合・引き継ぎを紹介します。
装置制御、試験データ解析、監視画面、3Dモデル・図面は、研究開発へ組み込む活用例として掲載しています。

## ページで見られること

- マクロ／ミクロの二層構成と、Claude Code / Codexでの役割別モデル例。
- 4つの洞察から設計する独立監査、工程への戻し、チェックリスト、記録の引き継ぎ。
- 合成データ6点の工程表示例：作業 → 2件の指摘 → 修正 → 再照合。タブで切り替えられます。
- 合成データ8試験の一覧・絞り込みと、同じページの波形モニター。
- 装置の全体・内部・組立図・部品図の切り替えと拡大。
- PLCのインターロック・独立遮断を含む装置制御の構成。

工程表示例はブラウザー内の再現表示です。公開ページからAI API・実機へは接続していません。
試験データは公開用の合成データ、人物画像はAI生成イメージ、掲載する装置は構想設計例です。
3Dはレンダリング画像とSVG図面を掲載しています。

## 主なファイル

- `index.html`：本文と画面の配置。
- `onepage.css`：PC・スマートフォンのレイアウト。
- `onepage.js`：試験の絞り込み、波形表示、図面の拡大。
- `assets/harness-flow.js`：ミクロハーネスの工程切り替え。
- `assets/monitor-data.js`：8試験の合成データ。
- `assets/`：画像、日本語フォント、利用許諾文。
- `details/cad/`：組立図・部品図のSVG。

## 手元で開く

Code → Download ZIP で展開し、`index.html`をブラウザーで開きます。
