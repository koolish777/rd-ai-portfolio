# sample | 研究開発・AIシステム設計

**[1ページの技術サンプルを開く](https://koolish777.github.io/rd-ai-portfolio/)**

装置制御、試験データ解析、AIを用いた開発を組み合わせた、個人の技術紹介資料です。

## ページの構成

- AIの実行管理・解析・照合・再計算・再照合の構成。
- 処理間のデータ受け渡し、9種類のデータを示すER図、関係と件数、保存項目。
- 実行権限、再計算回数、停止条件、自動点検。
- 正常・点検中・条件の見直し・設定の組み直しを切り替える監視画面と処理履歴。
- 低温通電試験の8試験の波形モニター、3Dモデル・組立図・部品図。
- 専用Hookによる画面内の確認依頼、3案の工程・期待値・担当者工数の比較、結果例から次の試験票への引き継ぎ。
- 作業量・API費用の試算、企業データの扱い。

試験データは公開用の合成データ、監視画面は状況の表示例、人物画像はAI生成イメージです。掲載する装置は構想設計例です。
3Dはレンダリング画像とSVG図面を掲載しています。
比較検討のHookはブラウザー内の通知として動作します。提案と再試験の結果例は表示用に用意したもので、選択とやり取りをページを開いている間保持します。

## 主なファイル

- `index.html`：本文、構成図、ER図。
- `onepage.css`：PC・スマートフォンの表示。
- `onepage.js`：監視画面の状況切り替え、処理履歴、波形、拡大表示、Hook通知と比較検討の操作。
- `assets/monitor-data.js`：8試験の合成データ。
- `assets/data-structure.svg`：拡大表示用のER図。
- `assets/`：画像、日本語フォント、利用許諾文。
- `details/cad/`：組立図・部品図のSVG。

## 手元で開く

Code → Download ZIP で展開し、`index.html`をブラウザーで開きます。
