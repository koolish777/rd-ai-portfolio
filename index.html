03 / HARNESS DESIGN

AIの4つの癖を、
工程の設計に変える。

担当を分ける理由と、仕事をつなぐ方法。
この4つの洞察を、ハーネスの設計に落とし込みます。

01

自己監査は、正当化を重ねやすい。

作業と監査を別の担当に。監査側は、原記録と確認基準から結果を見直します。

02

順番に流すだけでは、前へ戻れない。

工程ごとの状態と引き継ぎを残し、指摘のある工程へ戻ってやり直せる構成にします。

03

視点が変わると、見えるものが変わる。

解析、原記録の照合、研究者の現物確認。それぞれの視点で、原因候補を絞ります。

04

チェックリストに特化すると、監査は厳しくなる。

数値の出典、単位、抽出条件などを固定し、項目ごとに理由を添えて照合します。

04 / APPLICATION — TEST DATA

低温通電試験から、次の仮説へ。

ハーネスの活用例：低温通電試験。
計測ログの集計、原因候補の比較、再試験案の作成を、
作業・監査・引き継ぎの工程につなぎます。

試験条件

2ミリ秒の変化を、原波形から。

全点の集計で短い電圧低下を抽出し、温度や弁の動作と比較します。AIは接触・電源・温度などの原因候補を整理し、条件を一つずつ変える試験案と報告をまとめます。

−80°Cチャック温度（設計目標）
10kHz波形の取得条件
2ms電圧低下（合成データ）

試料温度とチャック温度は別チャンネルで測定します。以下の表示は合成データです。

1日の作業（5項目）

各タスクに作業と監査を組み、指揮AIが結果と次の依頼をまとめます。

  1. 01温度の整理

    試料とチャックの温度差、安定区間を集計します。

  2. 02波形の解析

    電圧の低下区間と継続時間を抽出します。

  3. 03原因候補の比較

    接触、電源、温度、弁の動作の関係を比較します。

  4. 04再試験条件の作成

    条件を1つずつ変える試験案を作成します。

  5. 05日次報告

    根拠と確認項目を添えて、試験担当者に報告します。

05 / APPLICATION — CONTROL

装置の動きと、
データの流れを一緒に設計。

温調・通電・計測のシーケンスから、
操作画面、記録、解析への受け渡しまでつなげます。

01 / 設定

試験条件を入力

温度・通電条件・保持時間を操作画面で設定。

02 / 制御

PLCで工程を進行

温調、通電、弁動作、計測の順序を制御。

03 / 計測

時刻をそろえて記録

試料・チャック温度、電圧、圧力、弁の動作を保存。

04 / 解析

比較と報告につなぐ

条件別に集計し、変化点と再試験案を画面へ。

装置側の保護設計

インターロックと、
PLCから独立した遮断系。

非常停止、扉ロック、温度インターロック、過電流保護を制御に組み込みます。温度上限リレーによるヒーターの独立遮断も、装置の保護系として設計します。

低温通電試験での保護機能を見る

この試験装置の設計例です。

機能入力条件動作復旧条件
非常停止非常停止ボタンの押下通電電源、ヒーター、ガス供給弁を遮断します。チャックの冷却と記録は継続します。ボタンを解除し、試験担当者が操作画面で復帰操作を行います。通電は再開条件の確認後に再開します。
扉ロックチャンバー扉の開放を検出通電を停止し、扉の開放時刻を記録します。扉を閉じ、担当者が再開操作を行います。
温度インターロック試料温度またはチャック温度が設定範囲外通電の開始を許可しません。通電中なら停止します。温度が範囲内に戻り、担当者が再開操作を行います。
過電流保護電流が設定上限を超過電源出力を遮断し、直前の波形と時刻を保存します。担当者が原因を確認し、上限値を再設定して再開します。
独立した遮断系温度上限リレーの作動（PLCとは独立）ヒーター電源を機械的に遮断します。担当者がリレーを手動でリセットします。

07 / APPLICATION — 3D & DRAWING

構想を立体に、寸法を図面に。

装置の配置、調整する場所、部品の取付位置を共有。
立体と図面を切り替え、具体的な検討につなげます。

3D CAD / DRAWING

対応する作業

  • 3Dモデル

    部品、アセンブリ、図面を作成します。業務用のアカウントと作業環境は依頼元で用意する形です。
